## 一、系统概述

交易审计追踪系统用于确保每笔交易数据全程可溯源，出问题时可快速定位和补救。

### 核心功能
1. **交易追踪**：记录所有资金变动（利润结算、代金券核销、人工调账等）
2. **余额快照**：定期记录推销员余额，用于对账和恢复
3. **自动告警**：检测余额不一致、重复结算、负余额等异常
4. **自动对账**：定时任务每日/周/月执行对账检查

## 六、已修复问题

### 6.1 人工调账事务超时
- **问题**：人工调账时事务超时（5秒）
- **原因**：在事务内调用createBalanceSnapshot，导致嵌套事务
- **修复**：将快照创建移到事务外部执行
- **状态**：✅ 已修复并验证

## 七、使用指南

### 7.1 查看推销员资金链路
```
GET /api/admin/audit/agent/{agentId}/traces
```
可查看该推销员所有交易记录，包括：
- 利润结算
- 代金券核销
- 人工调账
- 充值提现

### 7.2 追溯预约资金流向
```
GET /api/admin/audit/reservation/{reservationId}/trace
```
可追溯单笔预约的：
- 利润分配（总代、一级、二级）
- 赠品成本
- 使用的代金券

### 7.3 人工调账（补救）
```
POST /api/admin/audit/agent/{agentId}/adjust
Body: { "amount": 100, "reason": "补发奖励" }
```

### 7.4 手动触发对账
```
POST /api/admin/audit/reconciliation
Body: { "startDate": "2026-01-01", "endDate": "2026-01-22" }
```
