## 八、晋升流程API汇总

### 推销员端API
| 端点 | 方法 | 说明 |
|------|------|------|
| /api/commission/upgrade/status | GET | 获取晋升状态（含条件检查） |
| /api/commission/upgrade/apply | POST | 提交晋升申请 |
| /api/promotion/agent/upgrade/check | GET | 检查晋升资格 |
| /api/promotion/agent/upgrade/records | GET | 获取晋升申请记录 |

### 管理后台API
| 端点 | 方法 | 说明 |
|------|------|------|
| /api/admin/upgrade-applications | GET | 获取晋升申请列表 |
| /api/admin/upgrade-applications/:id/review | POST | 审核晋升申请 |
| /api/admin/upgrade-config | GET | 获取晋升配置 |
| /api/admin/upgrade-config | PUT | 更新晋升配置 |

### 晋升配置项（reward_configs表）
| configKey | 默认值 | 说明 |
|-----------|--------|------|
| upgrade_sales_threshold | 5000 | 申请晋升销售额门槛 |
| upgrade_orders_threshold | 20 | 申请晋升订单数门槛 |
| auto_upgrade_threshold | 5000 | 自动晋升销售额门槛 |
| auto_upgrade_enabled | true | 是否启用自动晋升 |
| upgrade_compensation | 1000 | 升级补偿金额（元）|
