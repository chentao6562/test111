## 二、已修复BUG

### BUG-001: 员工提现服务缺少行锁保护 (P1) - 已修复

**位置**: `server/src/services/staffWithdrawalService.ts`

**问题描述**:
- `reviewWithdrawal` 和 `completeWithdrawal` 函数未使用FOR UPDATE行锁
- 并发审核可能导致重复处理或数据不一致

**修复方案**:
- 为两个函数添加事务和FOR UPDATE行锁
- 参照推销员提现服务 `withdrawalService.ts` 的实现

**修复代码**:
```typescript
// 使用事务和行锁确保并发安全
return prisma.$transaction(async (tx) => {
  // 使用行锁获取提现记录（FOR UPDATE）
  const withdrawals = await tx.$queryRaw<any[]>`
    SELECT id, status, staffId, amount FROM staff_withdrawals WHERE id = ${id} FOR UPDATE
  `;
  // ...
});
```

**验证结果**: 10个并发请求只有1个成功，其余9个正确返回"已处理"
