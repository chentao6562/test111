# 🏮 蒙庆烟花业务模式说明

> **系统定位**：蒙庆内部代理商订货系统  
> **业务本质**：B2B批发订货 + 代理商裂变推广  
> **合规模式**：信息引导 + 线下交易

---

## 🔄 核心业务流程

### 1️⃣ 代理商入驻流程

```
新用户访问小程序
       ↓
  ┌────┴────┐
  ↓         ↓
自主申请   扫码申请（通过推广码）
  ↓         ↓
填写申请信息（姓名、电话、身份证、申请理由）
       ↓
   后台审核
       ↓
  ┌────┴────┐
  ↓         ↓
审核通过   审核拒绝
  ↓         ↓
成为代理商  通知原因
  ↓
获得代理商资格 + 专属推广码
  ↓
可以开始订货 + 推广
```

### 2️⃣ 代理商订货流程

```
代理商登录小程序
       ↓
浏览商品（批发价展示）
       ↓
选择商品加入订货单
       ↓
选择取货方式
  ┌────┴────┐
  ↓         ↓
到店自取   提前锁货（VIP锁货费¥80，满¥500免）
  ↓         ↓
填写信息   填写信息（核对凭证用）
       ↓
提交订货单
       ↓
在线支付（预付款/订金）
       ↓
库管备货
       ↓
  ┌────┴────┐
  ↓         ↓
到店自取   搬运师傅移入VIP库房
  ↓         ↓
到店提货   到店提货（凭码从VIP库房取）
       ↓
库管扫码核销
       ↓
订单完成 → 分润结算（T+1）
```

### 3️⃣ 代理商推广裂变流程

```
代理商A（一级）
       ↓
生成推广码/海报
       ↓
分享给潜在代理商B
       ↓
B扫码进入小程序
       ↓
B填写代理商申请
       ↓
后台审核通过
       ↓
B成为二级代理商（A的下级）
       ↓
B开始订货
       ↓
  ┌────┴────┐
  ↓         ↓
B获得订货折扣   A获得推广分润（B订单金额的一定比例）
```

### 4️⃣ 分润规则

```
┌─────────────────────────────────────────────────────────────────┐
│                     代理商分润规则                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  📊 订单金额 < ¥399                                             │
│  ├─ 一级代理商推广分润：下级订单金额 × 10%                      │
│  └─ 二级代理商推广分润：下级订单金额 × 2%                       │
│                                                                  │
│  📊 订单金额 ≥ ¥399                                             │
│  ├─ 一级代理商推广分润：下级订单金额 × 15%                      │
│  └─ 二级代理商推广分润：下级订单金额 × 3%                       │
│                                                                  │
│  💡 举例：                                                       │
│                                                                  │
│  一级代理商A 发展了 二级代理商B                                 │
│  B下单订货 ¥500                                                 │
│                                                                  │
│  → A获得推广分润：¥500 × 15% = ¥75                             │
│  → B如果也发展了下级C，C下单¥500                               │
│  → B获得推广分润：¥500 × 3% = ¥15                              │
│  → A获得团队分润：¥500 × 15% = ¥75                             │
│                                                                  │
│  ⏰ 结算时机：订单完成（到店提货核销）后 T+1 结算               │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

## 📦 库存管理流程

```
┌─────────────────────────────────────────────────────────────────┐
│                     库存管理说明                                 │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  📊 库存类型                                                     │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  总库存 = 可用库存 + VIP锁定库存                         │   │
│  │                                                          │   │
│  │  可用库存：可供代理商订货的库存                          │   │
│  │  VIP锁定库存：已被"提前锁货"订单锁定的库存               │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                  │
│  📊 库存变动场景                                                 │
│  ┌─────────────────────────────────────────────────────────┐   │
│  │  增加库存：                                              │   │
│  │  - 采购入库（供应商送货验收）                            │   │
│  │  - 盘点盘盈                                              │   │
│  │  - 订单取消（释放库存）                                  │   │
│  │                                                          │   │
│  │  减少库存：                                              │   │
│  │  - 销售出库（订单核销）                                  │   │
│  │  - 盘点盘亏                                              │   │
│  │  - 报损出库                                              │   │
│  │                                                          │   │
│  │  锁定库存（不减少总库存，但减少可用库存）：              │   │
│  │  - VIP锁货订单支付成功                                   │   │
│  │                                                          │   │
│  │  解锁库存：                                              │   │
│  │  - VIP锁货订单核销（转为出库）                           │   │
│  │  - VIP锁货订单取消（释放锁定）                           │   │
│  └─────────────────────────────────────────────────────────┘   │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### VIP锁货库存流转

```
代理商选择"提前锁货"支付成功
       ↓
商品从【可用库存】移入【VIP锁定库存】
       ↓
搬运师傅将实物移入VIP库房
       ↓
代理商到店提货，库管扫码核销
       ↓
【VIP锁定库存】减少，记录出库流水
```

### 库存盘点流程

```
创建盘点任务（选择盘点范围：全部/某分类）
       ↓
库管扫码/手动录入实盘数量
       ↓
系统自动计算盈亏
       ↓
确认完成盘点
       ↓
自动调整库存（盘盈入库/盘亏出库）
       ↓
记录库存流水
```

│                                                                  │

│     时机：订单支付成功后生成                                    │

│  4️⃣ 商品条码                                                    │
│     用途：入库扫码、库存管理                                    │
│     来源：商品包装自带（厂家印刷）                              │
