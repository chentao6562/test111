# 🎆 蒙庆烟花代理商系统 - 完整开发方案

> **版本**：V1.0  
> **更新日期**：2025年1月  
> **系统定位**：B2B批发订货 + 代理商裂变推广 + 库存履约管理

---

## 一、项目概述

### 1.1 业务背景

蒙庆烟花是内蒙古呼和浩特地区的烟花鞭炮批发商，主要面向周边代理商进行批发销售。当前业务痛点：

| 问题 | 现状 | 影响 |
|------|------|------|
| 代理商管理混乱 | 微信群+Excel记录 | 无法追踪层级关系和业绩 |
| 订货效率低 | 电话+微信沟通 | 易漏单、出错、耗时 |
| 库存管理粗放 | 手工记账 | 旺季缺货、盘点困难 |
| 分润计算复杂 | 月底手工算账 | 易出错、代理商不信任 |
| 裂变无法追踪 | 口头介绍 | 无法激励代理商推广 |

### 2.2 技术栈选型

| 层级 | 技术选型 | 版本 | 选型理由 |
|------|----------|------|----------|
| **小程序端** | uni-app (Vue3) | 3.x | 一套代码多端发布，生态成熟 |
| **管理后台** | Vue3 + Element Plus | 3.4+ / 2.4+ | 组件丰富，开发效率高 |
| **认证服务** | uniCloud uni-id | - | 开箱即用，手机号/微信登录 |

| **数据库** | MySQL | 8.0 | 关系型数据，事务支持好 |
| **缓存** | Redis | 7.x | 高性能，库存锁定场景 |
| **对象存储** | 阿里云OSS | - | 图片存储，CDN加速 |
| **部署** | 阿里云ECS | - | 稳定可靠 |

### 3.2 完整表结构

```sql
-- ============================================================
-- 数据库：mengqing_firework
-- 字符集：utf8mb4
-- ============================================================

-- ------------------------------------------------------------
-- 1. 管理员表
-- ------------------------------------------------------------
CREATE TABLE `admins` (
  `id` int unsigned NOT NULL AUTO_INCREMENT,
  `username` varchar(32) NOT NULL COMMENT '用户名',
  `password` varchar(128) NOT NULL COMMENT '密码(bcrypt)',
  `name` varchar(32) DEFAULT NULL COMMENT '姓名',
  `phone` varchar(20) DEFAULT NULL COMMENT '手机号',
  `avatar` varchar(255) DEFAULT NULL COMMENT '头像',
  `role` tinyint NOT NULL DEFAULT '2' COMMENT '角色:1超管,2运营,3财务',
  `status` tinyint NOT NULL DEFAULT '1' COMMENT '状态:1启用,0禁用',
  `last_login_at` datetime DEFAULT NULL COMMENT '最后登录时间',
  `last_login_ip` varchar(45) DEFAULT NULL COMMENT '最后登录IP',
  `created_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP,
  `updated_at` datetime NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COMMENT='管理员表';

-- ------------------------------------------------------------
-- 2. 用户表（代理商）
-- ------------------------------------------------------------
CREATE TABLE `users` (
  `id` bigint unsigned NOT NULL AUTO_INCREMENT,
  `uni_id` varchar(64) DEFAULT NULL COMMENT 'uniCloud用户ID',
  `openid` varchar(64) DEFAULT NULL COMMENT '微信openid',
  `unionid` varchar(64) DEFAULT NULL COMMENT '微信unionid',
  `phone` varchar(20) NOT NULL COMMENT '手机号',
  `nickname` varchar(64) DEFAULT NULL COMMENT '昵称',
  `avatar` varchar(255) DEFAULT NULL COMMENT '头像',
  `real_name` varchar(32) DEFAULT NULL COMMENT '真实姓名',
  `id_card` varchar(18) DEFAULT NULL COMMENT '身份证号',
  
  -- 代理商信息
  `agent_level` tinyint NOT NULL DEFAULT '0' COMMENT '代理等级:0普通,1一级,2二级',
  `agent_status` tinyint NOT NULL DEFAULT '0' COMMENT '代理状态:0未申请,1待审核,2通过,3拒绝',
  `parent_id` bigint unsigned DEFAULT NULL COMMENT '上级代理ID',
  `invite_code` varchar(16) DEFAULT NULL COMMENT '邀请码',
  `agent_at` datetime DEFAULT NULL COMMENT '成为代理时间',
  
  -- 账户信息
  `balance` decimal(10,2) NOT NULL DEFAULT '0.00' COMMENT '可提现余额',
```

## 四、API接口设计

### 4.1 接口规范

```typescript
// 统一响应格式
interface ApiResponse<T> {
  code: number;      // 状态码：0成功，非0失败
  message: string;   // 消息
  data?: T;          // 数据
}

// 分页请求
interface PageQuery {
  page?: number;     // 页码，默认1
  pageSize?: number; // 每页条数，默认20
}

// 分页响应
interface PageResult<T> {
  list: T[];         // 数据列表
  total: number;     // 总条数
  page: number;      // 当前页
  pageSize: number;  // 每页条数
}

// 错误码定义
enum ErrorCode {
  SUCCESS = 0,
  PARAM_ERROR = 400,
  UNAUTHORIZED = 401,
  FORBIDDEN = 403,
  NOT_FOUND = 404,
  SERVER_ERROR = 500,
  
  // 业务错误码 1000+
  TOKEN_INVALID = 1001,
  TOKEN_EXPIRED = 1002,
```

| 风险 | 概率 | 影响 | 应对措施 |
