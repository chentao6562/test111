## 一、系统概述

### 1.1 业务模式

**线上免费预约 + 线下全款付款**

蒙庆烟花预约系统采用O2O模式：
- **线上**：仅提供商品浏览和预约服务，不收取任何费用
- **线下**：客户到店付款、领取商品和赠品

### 3.3 状态说明

| 状态值 | 状态名 | 说明 | 客户可见 | 门店操作 |
|-------|-------|------|---------|---------|
| 0 | 待确认 | 新提交的预约 | 等待门店确认 | 拨打电话 |
| 1 | 确认中 | 门店正在联系 | 门店正在联系您 | 继续拨打/确认/取消 |
| 2 | 已确认 | 确认成功 | 预约成功，请按时到店 | 等待到店 |
| 3 | 已完成 | 核销完成 | 已完成 | 无 |
| 4 | 已取消 | 被取消 | 已取消 | 无 |
| 5 | 已过期 | 超时未到店 | 已过期 | 无 |
| 6 | 确认失败 | 联系不上 | 确认失败 | 无 |
