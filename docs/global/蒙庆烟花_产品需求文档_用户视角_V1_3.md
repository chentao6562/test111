## 一、产品概述

### 1.1 产品定位

蒙庆烟花代理商订货系统是一套内部批发订货平台，面向已注册的代理商提供在线订货、库存锁定和分润结算服务。系统采用【线上信息引导 + 线下到店交易】模式，确保合规运营。

### 1.2 核心价值

| 价值点 | 说明 |
|--------|------|
| 线上线下一体 | 门店零售与线上订购共用库存，统一管理 |
| 提前锁货 | 线上订购可申请锁货，防止到店时缺货 |
| 灵活代理模式 | 支持分润模式和差价销售模式，满足不同代理需求 |
| 全程可视 | 订单状态实时推送，代理商可查看完整处理流程 |
| 财务透明 | 所有收款、结算数据完整记录，支持对账 |

### 1.3 业务场景

系统需处理两种销售场景的库存协同：

| 场景 | 说明 | 库存处理 |
|------|------|----------|
| 门店零售 | 顾客到店现场购买 | 实时扣减库存 |
| 线上订购 | 代理商小程序下单预约 | 下单时锁定库存，提货时扣减 |

> **重要**：线上订购是预约订货，需要锁定库存防止超卖；门店零售是实时销售，直接扣减库存。

### 1.4 业务模式

系统支持两种代理模式：

**模式一：分润模式**

代理商按平台统一价销售，发展下级代理可获得订单分润。

- 一级代理商：直接与蒙庆合作，可发展下级代理（二级），获得下级订单分润
- 二级代理商：由一级代理发展而来，可发展三级代理，获得下级订单分润
- 三级代理商：由二级代理发展而来，不可再发展下级，可获得自身订单分润
- 分润比例（直接分润/间接分润）和金额门槛可在后台灵活配置

**模式二：差价销售模式（批发商订货）**

代理商以批发价进货，自主定价销售，赚取差价利润。

- 代理商按批发价订货
- 自主决定终端销售价格
- 利润 = 销售价 - 批发价
- 不参与分润体系

## 二、用户角色与权限

### 2.1 角色概览

| 角色 | 使用端 | 核心职责 |
|------|--------|----------|
| 代理商 | 代理商订货小程序 | 浏览商品、提交订货单、查看订单进度、管理团队、提现分润 |
| 库管 | 库管端小程序 | 接收订单通知、打印订单小票、备货、扫码核销 |
| 货管 | 货管端小程序 | 接收备货完成通知、查看客户信息、确认预约、VIP移库 |
| 管理员 | 管理后台（PC） | 代理商审核、订单管理、财务对账、分润配置、收款记录 |

### 2.2 代理商类型与权限

| 功能 | 一级代理商（分润） | 二级代理商（分润） | 三级代理商（分润） | 批发商（差价模式） |
|------|-------------------|-------------------|-------------------|-------------------|
| 浏览商品/订货 | 支持 | 支持 | 支持 | 支持 |
| 查看订单进度 | 支持 | 支持 | 支持 | 支持 |
| 生成推广码 | 支持 | 支持 | 支持 | 不适用 |
| 发展新代理商 | 支持（发展二级） | 支持（发展三级） | 不支持 | 不适用 |
| 查看团队/分润 | 支持 | 支持 | 仅分润 | 不适用 |
| 自主定价销售 | 不适用 | 不适用 | 不适用 | 支持 |

> **分润类型说明**：
> - **直接分润**：来自直接下级代理商订单的分润
> - **间接分润**：来自间接下级（下级的下级）代理商订单的分润
> - 例如：一级代理A发展了二级代理B，B发展了三级代理C，则C的订单产生时，B获得直接分润，A获得间接分润

## 三、代理商订货小程序功能

### 3.1 用户登录功能

#### 3.1.1 登录方式

系统支持多种登录方式，满足不同用户的使用习惯：

| 登录方式 | 说明 | 适用场景 | 开发状态 |
|----------|------|----------|----------|
| 微信授权登录 | 一键授权微信账号登录，自动获取头像和昵称 | 首次使用、快捷登录 | 【待开发】 |
| 手机号验证码登录 | 输入手机号，获取短信验证码登录 | 常规登录、换设备登录 | 已实现 |
| 手机号密码登录 | 输入手机号和密码登录 | 已设置密码的用户 | 已实现 |

> **注**：当前版本暂未实现微信授权登录，用户可使用手机号验证码或密码登录。

#### 3.1.2 登录流程

**微信授权登录流程**：

1. 用户打开小程序
2. 点击【微信一键登录】按钮
3. 系统弹出微信授权确认框
4. 用户点击【允许】授权
5. 系统获取用户微信信息，完成登录
6. 若为新用户，跳转至代理商入驻申请页面
7. 若为已注册代理商，直接进入首页

**手机号验证码登录流程**：

1. 用户点击【手机号登录】
2. 输入已注册的手机号
3. 点击【获取验证码】
4. 输入收到的6位短信验证码（60秒有效）
5. 点击【登录】完成验证
6. 登录成功，进入首页

**手机号密码登录流程**：

1. 用户点击【密码登录】
2. 输入手机号和密码
3. 点击【登录】
4. 验证通过，进入首页

#### 3.1.3 登录页面要素

| 要素 | 说明 | 必填 |
|------|------|------|
| 手机号 | 11位手机号码，需已注册 | 是（验证码/密码登录） |
| 验证码 | 6位数字，60秒有效期 | 是（验证码登录） |
| 密码 | 6-20位字符 | 是（密码登录） |
| 记住登录状态 | 勾选后7天内免登录 | 否 |
| 微信授权 | 授权获取微信头像昵称 | 是（微信登录） |

#### 3.1.4 登录安全规则

| 规则项 | 说明 |
|--------|------|
| 验证码有效期 | 60秒，过期需重新获取 |
| 验证码获取间隔 | 60秒内只能获取一次 |
| 密码错误限制 | 连续错误5次，账号锁定30分钟 |
| 验证码错误限制 | 连续错误5次，需等待10分钟 |
| 登录态有效期 | 默认7天，可选"记住登录" |
| 异地登录提醒 | 检测到异地登录，短信通知用户 |

#### 3.1.5 找回密码

忘记密码时可通过手机验证码重置：

1. 点击登录页【忘记密码】
2. 输入注册手机号
3. 获取并输入验证码
4. 设置新密码（6-20位，需包含数字和字母）
5. 确认新密码
6. 重置成功，返回登录页

#### 3.1.6 登录状态管理

| 场景 | 处理方式 |
|------|----------|
| Token过期 | 自动跳转登录页，提示"登录已过期，请重新登录" |
| 账号被冻结 | 提示"您的账号已被冻结，请联系客服" |
| 异地登录 | 发送短信通知，可选择强制下线其他设备 |
| 主动退出 | 清除本地登录态，返回登录页 |

### 3.2 用户注册与入驻

#### 3.2.1 入驻流程

新用户首次进入小程序时，需申请成为代理商：

1. 打开小程序，点击【申请成为代理商】
2. 选择代理模式：分润模式 或 差价销售模式
3. 填写申请信息：姓名、手机号、身份证号、申请理由
4. 提交申请，等待后台审核（1-3个工作日）
5. 审核通过后，获得代理商资格

#### 3.2.2 页面要素

| 要素 | 说明 | 必填 |
|------|------|------|
| 代理模式 | 分润模式 / 差价销售模式 | 是 |
| 姓名 | 真实姓名，用于身份核验 | 是 |
| 手机号 | 接收验证码和通知 | 是 |
| 身份证号 | 实名认证 | 是 |
| 申请理由 | 简要说明申请原因 | 否 |

### 3.3 商品浏览与订货

#### 3.3.1 商品列表

代理商登录后可浏览所有在售商品，页面展示：

- 商品图片、名称、规格
- 批发价格（代理商专享价）
- 库存状态：充足 / 紧张 / 缺货

支持按分类筛选、按价格/销量排序、关键词搜索。

#### 3.3.2 商品详情

点击商品进入详情页，展示：

- 商品轮播图

- 规格选择（如有多规格）

#### 3.3.3 订货单

代理商选购商品后，商品暂存于订货单：

### 3.4 提交订单与支付

#### 3.4.1 确认订单页

点击【去结算】后进入确认订单页，需填写或选择：

| 项目 | 说明 | 必填 |
|------|------|------|
| 联系人姓名 | 提货时核对身份 | 是 |
| 联系电话 | 接收通知，客服/货管联系用 | 是 |
| 预约提货时间 | 选择日期和时段 | 是 |
| 收货地址 | 用于核对凭证 | 否 |
| 优惠券 | 选择可用优惠券 | 否 |
| 备注 | 特殊要求说明（如需锁货可备注） | 否 |

#### 3.4.2 取货方式

所有订单默认为【到店自取】，用户可根据需要申请【锁货服务】：

| 方式 | 最低订货金额 | 说明 |
|------|-------------|------|
| 到店自取（默认） | 200元 | 备货完成后凭提货码到店提货 |
| 锁货服务（可选追加） | 400元 | 货物移入VIP库房锁定，防止缺货 |

#### 3.4.3 锁货服务申请流程

锁货服务是到店自取的追加服务，用户如需锁货：

1. 用户下单并支付货款（默认到店自取）
2. 用户如需锁货，主动联系客服申请
3. 客服确认锁货需求，在系统填入锁货费
4. 用户额外支付锁货费
5. 订单转为锁货流程，货物移入VIP库房

说明：

- 锁货服务为可选服务，不强制
- 锁货费由客服根据实际情况确定
- 管理员可在后台按日期设置锁货费基准价格
- 申请锁货的订单金额需满400元

#### 3.4.4 支付方式

支持以下支付方式：

- **预存款支付**：使用账户余额支付，需提前充值
- **到店付款**：先下单锁定库存，到店提货时现场付款

所有支付记录系统自动保存，用于财务对账。

### 3.5 订单管理与进度查看

#### 3.5.1 订单状态

| 状态 | 说明 | 代理商可操作 |
|------|------|-------------|
| 待付款 | 订单已创建，等待支付 | 去支付、取消订单 |
| 待接单 | 已支付，等待库管接单 | 查看详情、申请锁货 |
| 备货中 | 库管已接单正在备货 | 查看详情、申请锁货 |
| 待付锁货费 | （申请锁货）客服已填入锁货费 | 支付锁货费 |
| 待移库 | （锁货）备货完成，等待货管 | 查看进度 |
| 移库中 | （锁货）货管正在移库 | 查看进度 |
| 待提货 | 可以到店提货 | 查看提货码 |
| 已完成 | 已提货完成 | 再次订货 |
| 已取消 | 订单已取消 | 查看详情 |

> **申请锁货说明**：订单在【待接单】或【备货中】状态时，用户可联系客服申请锁货。客服确认后填入锁货费，订单变为【待付锁货费】。用户支付锁货费后，订单继续走锁货流程。

#### 3.5.2 订单进度可视化

代理商可实时查看订单处理进度：

- 订单时间线：显示每个状态节点的时间
- 当前处理人：显示库管/货管信息
- 预约确认状态：货管是否已确认预约时间
- 货管联系方式：可直接拨打电话沟通

#### 3.5.3 订单凭证（提货二维码）

订单支付成功后，代理商可在订单详情页查看订单凭证：

- 订单图文信息：商品清单、金额、取货方式等
- 提货二维码：贯穿整个流程的核心凭证
- 二维码动态刷新（防截图盗用）
- 显示手机尾号用于核验

> **重要**：提货二维码是库管、货管、客户之间完成货物交接的唯一凭证

二维码使用场景：

- 库管备货完成：扫码确认备货
- 货管移库交接：扫码确认接收货物
- 货管移库完成：扫码确认入库VIP库房
- 客户到店提货：出示二维码，库管扫码核销

## 四、库管端小程序功能

库管端供门店库管人员使用，负责订单接收、备货和核销。

### 4.1 订单接收与小票打印

#### 4.1.1 新订单通知

当有新订单支付成功时：

- 小程序收到推送通知（类似美团外卖接单）
- 播放提示音
- 显示新订单数量角标

#### 4.1.2 订单小票打印

库管点击订单可打印小票，包含：

- 订单编号、下单时间
- 代理商姓名、联系电话
- 商品清单（名称、规格、数量）
- 取货方式、预约时间
- 备注信息

### 4.2 订单备货

#### 4.2.1 待备货列表

显示所有待备货订单：

- 订单编号、代理商信息
- 商品数量、订单金额
- 取货方式标识（自取/锁货）
- 预约提货时间

#### 4.2.2 备货操作

1. 点击【开始备货】，订单状态变为「备货中」
2. 查看商品清单和库位信息
3. 按清单拣货，逐项勾选确认已拣货商品
4. 全部商品拣货完成后，点击【完成备货】
5. 扫描订单提货二维码确认备货完成

**备货清单勾选机制**：

| 功能 | 说明 |
|------|------|
| 商品列表 | 显示所有待拣货商品，包含名称、规格、数量、库位 |
| 勾选确认 | 每拣完一件商品，勾选对应条目 |
| 进度显示 | 显示已拣/总数，如「3/5」 |
| 全部完成 | 所有商品勾选后方可点击【完成备货】 |

备货完成后：

- 到店自取订单：状态变为【待提货】，通知代理商
- 提前锁货订单：状态变为【待移库】，通知货管

### 4.3 提货核销

代理商到店提货时：

1. 代理商在小程序打开订单凭证，出示提货二维码
2. 库管点击【扫码核销】
3. 扫描代理商的提货二维码
4. 核对订单信息和手机尾号
5. 确认核销，交付货物

核销成功后，订单完成，触发分润结算（如适用）。

### 4.4 门店零售

库管处理门店现场零售：

- 扫描商品条码，添加到销售单
- 确认收款（现金/扫码）
- 打印零售小票
- 库存实时扣减

零售时库存提示：

- 显示商品可售库存
- 如库存已被线上锁定，提示剩余可售数量
- 库存不足时无法完成销售

### 4.5 库存查询

库管可查询当前库存：

- 按商品名称/条码搜索
- 查看总库存、可售库存、线上锁定库存
- 查看VIP库房库存
- 库位信息查询

### 4.6 订单调换

备货过程中如遇商品问题，库管可进行商品调换：

#### 4.6.1 调换场景

| 场景 | 说明 |
|------|------|
| 库存不足 | 部分商品实际库存不足，需替换为同类商品 |
| 商品损坏 | 商品包装破损或质量问题，需更换 |
| 规格变更 | 客户临时要求更换规格 |

#### 4.6.2 调换流程

1. 在订单详情页点击【商品调换】
2. 选择需调换的商品
3. 选择替换商品（同价位或相近商品）
4. 填写调换原因
5. 提交调换申请
6. 系统自动通知代理商确认

#### 4.6.3 调换规则

- 调换需在备货阶段完成
- 调换商品价值差异超过10%需代理商确认
- 调换记录保留在订单详情中
- 财务按实际商品金额结算

### 4.7 异常上报

备货或核销过程中遇到异常情况，库管可上报处理：

#### 4.7.1 异常类型

| 类型 | 说明 |
|------|------|
| 库存异常 | 系统库存与实际不符 |
| 商品异常 | 商品损坏、过期、质量问题 |
| 订单异常 | 订单信息错误、重复订单 |
| 提货异常 | 代理商身份核验失败、二维码无效 |
| 其他异常 | 其他需要处理的情况 |

#### 4.7.2 上报流程

1. 点击【异常上报】按钮
2. 选择异常类型
3. 填写异常描述
4. 上传相关照片（可选）
5. 提交上报
6. 等待管理员/客服处理

#### 4.7.3 异常处理

- 异常工单自动推送至管理后台
- 客服介入处理并反馈结果
- 处理结果同步通知库管和代理商
- 异常记录保留备查

## 五、货管端小程序功能

货管端供货管（搬运师傅）使用，负责VIP移库任务。

### 5.1 任务通知

当库管备货完成（提前锁货订单）时：

- 货管收到推送通知
- 播放提示音
- 显示新任务角标

### 5.2 任务详情

货管点击任务查看：

- 货物清单：商品名称、规格、数量
- 取货库位：普通库位编号
- 目标位置：蒙庆VIP库房
- 客户信息：姓名、电话、地址（核对用）
- 预约提货时间
- 搬运费

### 5.3 预约确认

货管需确认客户预约时间：

1. 查看客户预约的提货时间
2. 如需调整，拨打客户电话沟通
3. 点击【确认预约】

确认后，客户端显示预约已确认状态。

### 5.4 移库操作

货管通过状态按钮完成货物交接流程：

#### 5.4.1 操作流程

1. 在任务详情页点击【确认接收】，确认从库管接收货物
2. 订单状态变为「移库中」
3. 将货物搬运到VIP库房
4. 点击【确认入库】，确认货物已入库VIP库房
5. 任务完成，订单状态变为「待提货」

#### 5.4.2 任务状态

| 状态 | 说明 | 可操作 |
|------|------|--------|
| 待接收 | 库管已备货完成，等待货管接收 | 【确认接收】 |
| 移库中 | 货管已接收，正在搬运 | 【确认入库】 |
| 已完成 | 货物已入库VIP库房 | 查看详情 |

完成后，代理商收到锁货成功通知。

> **注意**：客户地址仅作为核对凭证，货管工作范围为仓库内部移库，不涉及外出配送。

### 5.5 收入统计

货管可查看收入明细和进行提现：

#### 5.5.1 收入概览

| 统计项 | 说明 |
|--------|------|
| 今日收入 | 当日完成任务的搬运费总额 |
| 本周收入 | 本周累计搬运费 |
| 本月收入 | 本月累计搬运费 |
| 累计收入 | 历史总收入 |
| 可提现余额 | 当前可提现金额 |

#### 5.5.2 任务明细

显示每笔任务的详细信息：

- 任务编号、完成时间
- 订单编号、代理商信息
- 搬运费金额
- 结算状态（待结算/已结算）

#### 5.5.3 提现功能

- 最低提现金额：10元
- 提现手续费：暂免
- 到账时间：1-3个工作日
- 提现方式：微信零钱/银行卡

### 5.6 个人中心

货管个人中心包含以下功能：

| 功能 | 说明 |
|------|------|
| 个人信息 | 姓名、手机号、头像、认证状态 |
| 任务统计 | 累计任务数、本月任务数、完成率 |
| 收入入口 | 快捷进入收入统计页 |
| 提现记录 | 查看历史提现记录 |
| 联系客服 | 遇到问题联系平台客服 |
| 账号设置 | 修改手机号、修改密码 |
| 退出登录 | 退出当前账号 |

### 5.7 货管入驻申请

新用户可申请成为货管（搬运师傅）：

#### 5.7.1 申请条件

- 年龄18-55周岁
- 身体健康，能胜任搬运工作
- 有合法身份证明

#### 5.7.2 申请流程

1. 打开货管端小程序
2. 点击【申请成为货管】
3. 填写申请信息：
   - 姓名、手机号
   - 身份证号码
   - 紧急联系人
   - 个人简介（可选）
4. 上传身份证正反面照片
5. 提交申请，等待审核
6. 审核通过后，获得货管资格

#### 5.7.3 审核说明

- 审核时间：1-3个工作日
- 审核结果通过短信/小程序通知
- 审核不通过可重新提交申请

## 七、订单协同与通知机制

### 7.1 订单流转与二维码扫码节点

提货二维码贯穿整个订单流程，各角色通过扫码完成交接：

**标准流程（到店自取）**

| 阶段 | 操作 | 扫码动作 | 状态变更 |
|------|------|----------|----------|
| 1.下单支付 | 代理商提交并支付 | 生成提货二维码 | 待接单 |
| 2.库管接单 | 库管收到通知 | - | 备货中 |
| 3.备货完成 | 库管完成拣货 | 扫码确认备货 | 待提货 |
| 4.客户提货 | 代理商到店提货 | 扫码核销交付 | 已完成 |

**锁货流程（追加锁货服务）**

用户在【待接单】或【备货中】阶段可联系客服申请锁货：

| 阶段 | 操作 | 扫码动作 | 状态变更 |
|------|------|----------|----------|
| 1.下单支付 | 代理商提交并支付货款 | 生成提货二维码 | 待接单 |
| 2.申请锁货 | 用户联系客服申请锁货 | - | - |
| 3.确认锁货费 | 客服填入锁货费金额 | - | 待付锁货费 |
| 4.支付锁货费 | 代理商支付锁货费 | - | 继续原流程 |
| 5.库管备货 | 库管备货完成 | 扫码确认备货 | 待移库 |
| 6.货管接收 | 货管从库管接货 | 扫码确认接收 | 移库中 |
| 7.移库完成 | 货管入库VIP库房 | 扫码确认入库 | 待提货 |
| 8.客户提货 | 代理商到店提货 | 扫码核销交付 | 已完成 |

### 7.2 库管端通知

- 新订单提醒：推送通知 + 提示音（类似美团接单）
- 订单小票打印：接单后可打印备货小票
- 备货超时提醒：超过设定时间未备货提醒

### 7.3 货管端通知

- 新任务提醒：备货完成后推送
- 客户信息：可查看客户电话、预约时间
- 预约确认：在系统中确认预约，客户可见

### 7.4 代理商端通知

- 订单状态变更：每个节点推送通知
- 预约确认通知：货管确认后收到通知
- 提货提醒：可提货时推送

### 9.3 分润规则（可配置）

以下为默认配置，可在后台调整：

#### 9.3.1 直接分润比例

直接分润：来自直接下级代理商订单的分润。

| 订单金额 | 一级代理分润 | 二级代理分润 | 三级代理分润 |
|----------|-------------|-------------|-------------|
| 小于399元 | 10% | 8% | 5% |
| 399元及以上 | 15% | 12% | 8% |

#### 9.3.2 间接分润比例

间接分润：来自间接下级（下级的下级）代理商订单的分润。

| 订单金额 | 一级代理分润 | 二级代理分润 |
|----------|-------------|-------------|
| 小于399元 | 2% | 1% |
| 399元及以上 | 3% | 2% |

> **说明**：三级代理商无下级，不涉及间接分润。

#### 9.3.3 分润计算示例

假设三级代理C下单500元：

1. C的直接上级B（二级代理）获得直接分润：500 × 12% = 60元
2. B的上级A（一级代理）获得间接分润：500 × 3% = 15元

#### 9.3.4 分润规则说明

- 仅分润模式代理商参与
- 自己订货不产生分润（三级代理除外，三级代理自身订单可获分润）
- 分润比例、金额门槛可在后台配置
- 差价模式代理商不参与分润
- 分润在订单完成后T+2日结算

| 到账时间 | 财务确认后1-3个工作日 |

### 9.5 库存规则

#### 9.5.1 库存类型

| 库存类型 | 说明 |
|----------|------|
| 总库存 | 门店实际库存数量 |
| 可售库存 | 可供销售的库存 = 总库存 - 线上锁定 |
| 线上锁定库存 | 线上订单已锁定，待提货的库存 |
| VIP库房库存 | 已移入VIP库房的锁货订单库存 |

#### 9.5.2 线上线下库存协同

门店零售和线上订购共用库存，处理逻辑如下：

| 场景 | 操作 | 库存变化 |
|------|------|----------|
| 门店零售 | 顾客现场购买 | 可售库存实时扣减 |
| 线上下单 | 代理商支付订单 | 锁定库存（可售库存减少） |
| 线上提货 | 代理商到店核销 | 锁定库存转为已售 |
| 线上取消 | 订单取消/超时 | 释放锁定（可售库存恢复） |
| 申请锁货 | 支付锁货费后 | 锁定库存移入VIP库房 |

#### 9.5.3 库存冲突处理

当可售库存不足时：

- 线上下单：提示库存不足，无法下单
- 门店零售：如商品已被线上锁定，需等待或联系线上客户协商
- 库存预警：低库存时系统自动提醒管理员

> **建议**：旺季期间为线上订购预留一定库存额度，避免线上线下冲突。
