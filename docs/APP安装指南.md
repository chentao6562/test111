## 安装步骤

### 第一步：下载APK文件
1. 使用手机浏览器扫描二维码或点击下载链接
2. 等待下载完成（约2.3MB）

### 第二步：允许安装未知来源应用

> **重要**：Android系统默认禁止安装非应用商店的App，需要手动开启权限。

**不同手机品牌的设置方法：**

#### 华为/荣耀手机
1. 点击下载的APK文件
2. 弹出提示时，点击【设置】
3. 打开【允许来自此来源的应用】
4. 返回继续安装

#### 小米/红米手机
1. 点击下载的APK文件
2. 弹出"安全风险"提示，点击【继续安装】
3. 如需要，前往：设置 → 隐私保护 → 特殊应用权限 → 安装未知应用
4. 找到浏览器，开启权限

#### OPPO/一加手机
1. 点击下载的APK文件
2. 弹出提示时，点击【继续安装】
3. 如需要，前往：设置 → 安全 → 安装外部来源应用
4. 找到浏览器，开启权限

#### vivo/iQOO手机
1. 点击下载的APK文件
2. 弹出提示时，点击【继续安装】
3. 如需要，前往：设置 → 安全与隐私 → 更多安全设置 → 外部来源应用
4. 找到浏览器，开启权限

#### 三星手机
1. 点击下载的APK文件
2. 弹出提示时，点击【设置】
3. 打开【允许此来源】
4. 返回继续安装

### 第三步：完成安装
1. 点击【安装】按钮
2. 等待安装完成
3. 点击【完成】或【打开】

## 解决"不安全"提示

### 为什么会提示不安全？
这是Android系统的保护机制，所有非Google Play/应用商店下载的App都会显示此提示。**这不代表应用本身有风险**，蒙庆烟花App是公司内部使用的正规应用。

### 常见提示及处理方法

#### 提示："为了您的安全，手机已禁止安装..."
**解决方法**：点击【设置】→ 开启【允许此来源】→ 返回继续安装

#### 提示："此应用可能存在风险"
**解决方法**：点击【仍然安装】或【继续安装】

#### 提示："发送到手机管家检测"（华为）
**解决方法**：点击【取消】，然后点击【继续安装】

#### 提示："安装包解析失败"
**解决方法**：
1. 删除已下载的文件，重新下载
2. 检查手机存储空间是否充足
3. 确认Android版本不低于7.0

## 常见问题

### Q1：安装后打不开/闪退？
**解决方法**：
1. 确认手机Android版本 ≥ 7.0
2. 清除应用缓存后重试
3. 卸载后重新安装

### Q2：页面一直加载不出来？
**解决方法**：
1. 检查手机是否连接网络
2. 尝试切换WiFi/移动数据
3. 关闭应用后重新打开

### Q3：扫码功能不能用？
**解决方法**：
1. 前往手机设置 → 应用管理 → 蒙庆烟花 → 权限
2. 开启【相机】权限
3. 重启应用

### Q4：如何更新App？
**解决方法**：
1. 下载新版本APK
2. 直接安装即可覆盖旧版本
3. 数据会保留，无需重新登录
