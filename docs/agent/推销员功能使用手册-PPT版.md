# 第一部分
## 什么是推销员？

---

# 推销员是什么？

**简单来说：帮门店推广烟花的合作伙伴**

您的工作很简单：
1. 把商品链接分享给朋友
2. 朋友通过您的链接预约
3. 朋友到店付款后，您赚利润！

---

# 推销员的优势

## 您不需要：
- ❌ 自己囤货
- ❌ 自己送货
- ❌ 垫付任何费用

## 您只需要：
- ✅ 分享您的专属链接
- ✅ 设置好商品价格
- ✅ 等着收钱！

---

# 推销员的两种类型

| 类型 | 说明 | 特点 |
|------|------|------|
| **一级推销员** | 直接向平台拿货 | 可发展下级，能赚团队差价 |
| **二级推销员** | 向一级推销员拿货 | 赚自己销售的利润 |

> 一级推销员的拿货价更低，下级卖出的每一单您都有收益！

---

# 赚钱的核心原理

## 您的利润 = 客户支付价格 - 您的拿货价

**举个例子：**

- 您的拿货价：**70元**
- 您设置零售价：**100元**
- 客户付款：**100元**

**您的利润 = 100 - 70 = 30元**

> 价格您说了算！定得越高，赚得越多！

# 第二部分
## 5步快速上手

---

# 第一步：登录账号

1. 打开系统链接
2. 输入手机号
3. 获取验证码
4. 输入验证码登录

---

# 第二步：设置商品价格

**路径：个人中心 → 定价管理**

- 为每个商品设置您的零售价
- 零售价必须 ≥ 拿货价
- 可参考系统给的"建议零售价"

> ⚠️ 一级推销员必须设置"给下级的价"，否则下级无法销售！

---

# 第三步：获取推广链接

**路径：个人中心 → 推广中心**

- 保存您的专属二维码
- 或复制您的专属链接

---

# 第四步：分享给客户

- 把二维码/链接发给朋友
- 发朋友圈、微信群
- 客户扫码后看到的是**您设置的价格**

---

# 第五步：等待收益

1. 客户预约成功
2. 门店电话确认
3. 客户到店付款提货
4. **利润自动到您账户！**

# 定价管理（重点！）

**路径：个人中心 → 定价管理**

| 价格名称 | 含义 | 谁能看到 |
|---------|------|---------|
| 拿货价 | 您的成本价 | 只有您 |
| 建议零售价 | 系统推荐价 | 只有您 |
| 零售价 | 卖给客户的价 | 客户能看到 |
| 给下级的价 | 给二级的成本价 | 只有下级 |

---

# 定价举例（一级推销员）

**某款烟花：**
- 您的拿货价：50元
- 您设置给下级的价：70元
- 您设置零售价：100元

**收益情况：**
- 您直接卖：100-50 = **50元**
- 下级卖出：您赚 70-50 = **20元**

# 第四部分
## 预约下单流程

---

# 帮客户下单流程

```
添加商品到采购单
      ↓
调整数量、查看金额
      ↓
点击"去结算"
      ↓
填写客户信息（姓名、电话）
      ↓
选择提货日期
      ↓
提交预约
```

> 💡 预约免费，客户不需要在线支付！

---

# 预约状态流程

```
待确认 → 已确认 → 待备货 → 待提货 → 已完成
   ↓
门店30分钟内电话确认
```

**已完成 = 利润到账！**

---

# 预约状态说明

| 状态 | 说明 |
|------|------|
| 待确认 | 刚提交，等待门店联系 |
| 已确认 | 门店已电话确认 |
| 待备货 | 提货日期临近 |
| 待提货 | 商品已备好 |
| **已完成** | 客户付款提货，**利润到账！** |
| 已取消 | 客户取消了 |

# 利润计算方式

## 直接销售利润
您的利润 = 客户支付价格 - 您的拿货价

## 团队利润（一级专属）
您的利润 = 给下级的价 - 您的拿货价

> 核销即时到账！客户付款后利润立刻进入余额
