# 第一章：快速入门（新手必读）

## 1.1 推销员是什么？

简单来说，推销员就是**帮门店推广烟花的合作伙伴**。

您的工作很简单：
1. 把商品链接分享给身边的朋友
2. 朋友通过您的链接预约购买
3. 朋友到店付款提货后，您就能赚到利润

**您不需要：**
- ❌ 自己囤货
- ❌ 自己送货
- ❌ 垫付任何费用

**您只需要：**
- ✅ 分享您的专属链接
- ✅ 设置好商品价格
- ✅ 等着收钱

## 1.2 推销员的两种类型

| 类型 | 说明 | 特点 |
|------|------|------|
| **一级推销员** | 直接向平台拿货 | 可以发展下级团队，能赚团队差价 |
| **二级推销员** | 向一级推销员拿货 | 赚自己销售的利润 |

> 💡 **小提示**：一级推销员的拿货价更低，而且下级卖出的每一单您都有收益！

## 1.3 赚钱的核心原理

这是最重要的一点，请务必理解：

```
您的利润 = 客户支付的价格 - 您的拿货价
```

**举个例子：**

假设有一款烟花：
- 您的拿货价是 **70元**
- 您设置零售价为 **100元**
- 客户付款 **100元**

那么：**您的利润 = 100 - 70 = 30元**

> 🎯 **关键点**：价格您说了算！在不低于拿货价的前提下，您可以自由定价。定得越高，赚得越多！

## 1.4 如何成为推销员？

**方式一：通过邀请码注册**
1. 向已有的推销员索取邀请码
2. 打开系统，使用手机号登录
3. 输入邀请码完成绑定
4. 成为该推销员的下级

**方式二：申请升级**
1. 先以普通用户身份使用系统
2. 进入"个人中心"
3. 点击"申请成为推销员"
4. 等待审核通过

## 1.5 第一次使用该怎么做？

按照这5步来，马上开始赚钱：

### 第一步：登录账号
- 打开系统链接
- 输入手机号
- 获取验证码并登录

### 第二步：设置商品价格
- 进入"个人中心" → "定价管理"
- 为每个商品设置您的零售价
- 建议：可以参考系统给的"建议零售价"

### 第三步：获取推广链接
- 进入"个人中心" → "推广中心"
- 保存您的专属二维码
- 或复制您的专属链接

### 第四步：分享给客户
- 把二维码/链接发给朋友、发朋友圈
- 客户扫码后看到的价格就是您设置的价格

### 第五步：等待收益
- 客户预约成功后，门店会电话确认
- 客户到店付款提货
- 利润自动到您账户！

# 第二章：商品与预约

## 2.1 浏览商品

打开系统后，您可以通过以下方式找到想要的商品：

### 首页推荐
- 系统首页会展示热销商品和推荐商品
- 直接点击商品即可查看详情

### 分类查找
- 点击底部的"分类"标签
- 按烟花类型浏览（如：喷花类、组合烟花、小型烟花等）

### 搜索功能
- 在首页顶部输入关键词搜索
- 比如搜"加特林"、"仙女棒"等

## 2.2 设置商品价格（定价管理）

这是**最重要的功能**，直接决定您能赚多少钱！

### 进入方式
"个人中心" → "定价管理"

### 页面上的价格说明

| 价格名称 | 含义 | 谁能看到 |
|---------|------|---------|
| 拿货价 | 您从上级拿货的成本价 | 只有您能看到 |
| 建议零售价 | 系统推荐的售价，仅供参考 | 只有您能看到 |
| 零售价 | 您设置的卖给客户的价格 | 客户能看到 |
| 给下级的价 | 您给二级推销员的拿货价（一级专属） | 只有您的下级能看到 |

### 如何设置价格

1. 找到要设置的商品
2. 点击"设置价格"
3. 输入您想卖的价格（必须 ≥ 拿货价）
4. 点击"保存"

### ⚠️ 一级推销员特别注意

**如果您是一级推销员，必须同时设置"给下级的价"，否则您的下级无法销售该商品！**

设置建议：
- "给下级的价"要高于您的拿货价（这样您能赚差价）
- "给下级的价"要低于零售价（给下级留利润空间）

**举例：**
- 您的拿货价：50元
- 您设置"给下级的价"：70元
- 您设置零售价：100元

这样：
- 您直接卖给客户，赚 100-50 = **50元**
- 您的下级卖给客户（假设也卖100元），您赚 70-50 = **20元**，下级赚 100-70 = **30元**

### 批量设置功能

如果商品很多，一个个设置太麻烦，可以使用"一键设为建议价"功能，快速完成设置。

## 2.3 帮客户下单（采购单流程）

当客户想要购买时，您可以帮他们操作：

### 第一步：添加商品
- 在商品详情页点击"加入采购单"
- 或直接点击"立即预约"

### 第二步：查看采购单
- 点击底部的"采购单"标签
- 可以看到已添加的所有商品

### 第三步：调整数量
- 点击 + 或 - 调整商品数量
- 不需要的商品可以删除

### 第四步：查看金额和赠品
- 页面底部显示总金额
- 根据金额，系统会提示可获得的赠品

### 第五步：提交预约
1. 点击"去结算"
2. 填写客户信息（姓名、电话）
3. 选择预计提货日期
4. 点击"提交预约"

> 💡 **重要提醒**：预约是免费的，客户不需要在线支付任何费用！

## 2.4 预约后的流程

预约提交后，会经过以下流程：

```
待确认 → 已确认 → 待备货 → 待提货 → 已完成
   ↓
门店30分钟内电话确认
```

### 各状态说明

| 状态 | 说明 | 您需要做什么 |
|------|------|-------------|
| **待确认** | 刚提交的预约 | 等待门店联系客户 |
| **已确认** | 门店已电话确认 | 等待客户到店 |
| **待备货** | 提货日期临近 | 门店准备商品 |
| **待提货** | 商品已备好 | 提醒客户去提货 |
| **已完成** | 客户已付款提货 | 🎉 利润到账！ |
| **已取消** | 客户取消了预约 | 无收益 |
| **确认失败** | 电话联系不上客户 | 可以主动联系客户 |

## 2.5 查看我的预约

### 进入方式
"个人中心" → "我的预约"

### 功能说明
- 按状态筛选：全部、待确认、已确认、已完成等
- 点击预约可查看详情
- 查看预约的商品、金额、赠品信息

## 2.6 套餐购买【2026-01-25新增】

### 什么是套餐？

套餐是多个商品的组合，为特定场景精心搭配，一次性购买更省心！

**套餐特点：**
- 🎁 组合优惠，整体价格更划算
- 🎯 场景定位清晰（如"家庭欢乐套"、"浪漫烟花套装"）
- ⏱️ 省去自己搭配的麻烦

### 如何浏览套餐？

1. **首页入口**：点击"套餐专区"横幅
2. **分类入口**：从"分类"页面点击"套餐"分类
3. **浏览方式**：套餐按场景分类，可以横向滑动切换

### 套餐定价管理

和普通商品一样，您也需要为套餐设置零售价：

"个人中心" → "定价管理" → 找到套餐，设置价格

| 价格名称 | 含义 |
|---------|------|
| 拿货价 | 您从上级拿货的成本 |
| 建议零售价 | 平台推荐的售价 |
| 您的零售价 | 您自己定的卖价（不能低于拿货价） |

### 套餐预约流程

1. 进入套餐详情页
2. 点击"加入采购单"
3. 填写客户信息（姓名、电话、提货日期）
4. 提交预约

**注意事项：**
- 套餐不参与砍价、拼团等营销活动
- 套餐作为整体销售，不能拆分
- 利润计算方式与普通商品相同

# 第三章：收益与提现

## 3.1 分润中心功能介绍

这里是查看您所有收益的地方！

### 进入方式
"个人中心" → "分润中心"

### 页面上的数字说明

| 名称 | 含义 |
|------|------|
| **可提现余额** | 当前可以申请提现的金额 |
| **累计分润** | 您历史上总共赚了多少钱 |
| **本月分润** | 这个月赚了多少 |
| **待结算** | 已确认但还没到账的利润 |

## 3.2 利润如何计算？

### 直接销售利润

当客户通过您的链接预约并完成提货：

```
您的利润 = 客户支付价格 - 您的拿货价
```

### 团队利润（一级推销员专属）

当您的下级推销员卖出商品：

```
您的利润 = 您给下级的价 - 您的拿货价
```

### 计算实例

**场景：某款烟花**
- 一级推销员拿货价：50元
- 一级给二级的价：70元
- 二级设置零售价：100元

| 销售情况 | 一级利润 | 二级利润 |
|---------|---------|---------|
| 一级直接卖（卖100元） | 100-50=**50元** | - |
| 二级卖出（卖100元） | 70-50=**20元** | 100-70=**30元** |

### 利润什么时候到账？

**核销即时到账！** 只要客户到店付款完成提货，利润立刻进入您的余额。

## 3.3 申请提现

### 提现条件
- 余额满 **100元** 才能申请提现

### 提现步骤
1. 进入"分润中心"
2. 点击"申请提现"
3. 输入提现金额
4. 确认提现信息
5. 等待管理员审核

### 提现审核
- 管理员会在1-3个工作日内审核
- 审核通过后，款项会打到您的账户
- 如果被拒绝，金额会退回到余额

## 3.4 查看分润记录

在"分润中心"页面，您可以：
- 查看每一笔收益的来源
- 筛选"直接分润"（自己卖的）和"间接分润"（下级卖的）
- 查看收益对应的预约订单

# 第四章：推广获客

## 4.1 推广中心概览

推广中心是您获取客户的核心阵地！

### 进入方式
"个人中心" → "推广中心"

### 两种推广方式
1. **分享给客户** - 让客户下单，赚销售利润
2. **邀请推销员** - 发展下级团队，赚团队利润

## 4.2 分享给客户（获取订单）

### 您的专属二维码
- 在推广中心页面可以看到您的二维码
- 长按保存到手机
- 分享给朋友、发朋友圈

### 您的专属链接
- 点击"复制链接"
- 可以发到微信群、朋友圈、短信等

### 客户扫码后会看到什么？
- 进入商品浏览页面
- 看到的价格是**您设置的零售价**
- 客户预约后，业绩归您！

## 4.3 邀请下级推销员（扩大团队）

> 💡 **重要提醒**：只有一级推销员可以发展下级团队

### 您的邀请码
- 在推广中心可以看到您的专属邀请码
- 把邀请码告诉想加入的朋友

### 邀请流程
1. 朋友打开系统注册
2. 输入您的邀请码
3. 朋友成为您的下级推销员
4. 朋友卖出商品，您也有收益！

### 邀请的好处
- 每邀请一个新推销员，可获得 **15元代金券**
- 被邀请人激活后，再奖励 **20元代金券**
- 下级每卖一单，您都能赚差价

## 4.4 查看推广数据

在推广中心，您可以看到：
- 累计邀请人数
- 本月新增邀请
- 邀请记录详情（点击查看）

## 4.5 推广资料下载

### 进入方式
"推广中心" → "推广资料"

### 可用资料
- 宣传海报图片
- 推广文案模板
- 产品介绍资料

### 使用建议
- 海报可以直接发朋友圈
- 文案可以配合海报使用
- 记得在文案后附上您的二维码

# 第五章：团队管理（一级推销员专属）

- 查看下级带来的客户预约
- 了解预约状态和进度

- 要能看到发布平台

# 第十章：常见问题解答

## 推广相关

### Q：客户扫了我的码但没下单怎么办？
**A**：这很正常，客户可能还在考虑。您可以：
- 主动联系客户，了解顾虑
- 介绍当前的优惠活动
- 发送更多商品信息

### Q：我设置的价格客户能看到吗？
**A**：是的！客户扫您的二维码后，看到的就是您设置的零售价。

### Q：下级推销员的客户算我的业绩吗？
**A**：算！下级每卖出一单，您都能赚取差价（您给下级的价 - 您的拿货价）。

### Q：为什么我的下级说看不到某些商品？
**A**：很可能是您还没有给这些商品设置"给下级的价"。请到"定价管理"检查并设置。

## 收益相关

### Q：利润什么时候到账？
**A**：**核销即时到账！** 客户到店付款完成提货后，利润立刻进入您的余额。

### Q：为什么我的余额变成负数了？
**A**：可能是您使用了代金券。代金券核销时会从余额扣除等额金额，如果余额不足就会变成负数。别担心，下次有利润结算时会自动补齐。

### Q：提现多久能到账？
**A**：提现需要管理员审核，通常1-3个工作日内处理。审核通过后款项会打到您的账户。

### Q：为什么我的利润比预期少？
**A**：可能的原因：
- 赠品成本会从利润中扣除
- 客户参与了砍价活动，砍掉的金额可能由您承担部分
- 请在"分润记录"中查看详细的利润明细

## 代金券相关

### Q：代金券可以给别人用吗？
**A**：不可以。代金券只能推销员本人在门店使用。

### Q：代金券过期了还能用吗？
**A**：不能。代金券有效期至2026年2月14日，过期作废，请及时使用！

### Q：为什么我的奖励没到账？
**A**：请检查：
- 是否满足奖励条件（如首单奖励需要客户完成付款提货）
- 周期奖励是每周一结算，请耐心等待
- 如果确实有问题，请联系客服

### Q：我有多张代金券，可以一起用吗？
**A**：可以的，在门店消费时可以叠加使用多张代金券。

## 预约相关

### Q：客户不来提货怎么办？
**A**：
- 门店会在提货日期前一天提醒客户
- 如果客户确实不来，预约会变成"已过期"状态
- 您没有收益，但也不会有损失

### Q：预约可以修改吗？
**A**：
- 预约确认前可以取消重新下单
- 确认后需要联系门店协商修改

### Q：赠品是门店发还是我发？
**A**：赠品由门店在客户提货时一起发放，您不需要准备赠品。

## 其他问题

### Q：忘记登录密码怎么办？
**A**：系统使用手机验证码登录，不需要密码。每次登录只需输入手机号获取验证码即可。

### Q：如何升级为一级推销员？
**A**：目前一级推销员由平台直接发展，如果您业绩优秀，可以联系客服申请升级。

### Q：遇到系统问题找谁？
**A**：请联系客服：
- 电话：13190531439 / 15849390600
