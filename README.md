# 蒙庆烟花代理商订货系统

**B2B批发订货平台** | **四端架构** | **已上线运营**

## 📋 项目简介

蒙庆烟花代理商订货系统是一套内部批发订货平台，采用**线上信息展示 + 线下到店提货**的合规运营模式，支持三级代理体系和分润结算。

**门店地址**: 呼和浩特市和林格尔县盛乐镇姑子板村华门世家1号门面房
**客服电话**: 13190531439 / 15849390600
**上线时间**: 2026-01-12

## 🚀 快速开始

### 1. 环境要求
- **Node.js**: >= 18.0.0
- **数据库**: MySQL 8.0
- **包管理器**: npm
- **进程管理**: PM2

### 2. 后端启动
```bash
cd server
npm install
npx prisma generate
npm run dev
```

### 3. 管理后台启动
```bash
cd admin
npm install
npm run dev
```

### 4. 微信小程序开发
使用微信开发者工具打开对应目录：
- 代理商端: `miniprogram-agent/`
- 货管端: `miniprogram-logistics/`

## 🎯 核心功能

### 代理商端
✅ 商品浏览与搜索
✅ 订货单管理（购物车）
✅ 订单提交与跟踪
✅ VIP移库服务
✅ 提货二维码（60秒自动刷新）
✅ 分润中心（余额、提现、记录）
✅ 推广中心（邀请码、团队管理）

### 库管端
✅ 订单工作台（状态筛选）
✅ 提货核销（自提/锁货交接）
✅ 库存管理（入库、调整、盘点）
✅ 扫码查询商品（条形码/SKU）
✅ 库存预警

### 货管端
✅ 移库任务管理
✅ 订单抢单系统
✅ 提货核销（锁货模式）
✅ 收入统计
✅ 提现功能

### 管理后台
✅ 20个功能模块（代理商、商品、订单、库存、财务等）
✅ 移库管理（撮合打包、移库费设置）
✅ 分润管理（T+1结算、提现审批）
✅ H5素材管理（轮播图、推荐商品、公告）
✅ 数据统计与报表
