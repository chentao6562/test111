## 四、常见问题处理

### 4.1 PM2服务无响应

```bash
# 重启PM2服务
ssh root@39.104.58.26 "pm2 restart firework-api"

# 如果重启失败，查看日志
ssh root@39.104.58.26 "pm2 logs firework-api --lines 100"

# 如果需要完全重启
ssh root@39.104.58.26 "pm2 delete firework-api && cd /root/projects/test111/server && pm2 start dist/app.js --name firework-api"
```

### 4.2 数据库连接失败

```bash
# 检查RDS白名单是否包含服务器IP
# 在阿里云RDS控制台检查白名单配置

# 测试数据库连接
mysql -h rm-hp39t0j1y3xo2a25g.mysql.huhehaote.rds.aliyuncs.com \
  -P 3306 -u yanhuaxitong -pc65623518+ -e "SELECT 1"
```

### 4.3 分润未自动结算

**检查定时任务**：
```bash
# 查看PM2日志，搜索"T+1分润结算"
ssh root@39.104.58.26 "pm2 logs firework-api --lines 200 | grep '分润结算'"

# 手动触发结算（测试用）
cd /root/projects/test111/server
node -e "
const { PrismaClient } = require('@prisma/client');
const prisma = new PrismaClient();
const { settleCommissionsByDate } = require('./dist/services/commission/commissionRuleService');
const yesterday = new Date();
yesterday.setDate(yesterday.getDate() - 1);
settleCommissionsByDate(yesterday).then(r => console.log('结算完成', r));
"
```

### 4.4 监控发现数据不一致

**余额与流水不一致**：
1. 查看监控输出，找到不一致的代理商ID
2. 检查该代理商的所有fund_flows记录
3. 检查该代理商的所有commissions记录
4. 如果是历史数据问题，参考[补录资金流水脚本](server/backfill-fundflows.js)

**订单缺失分润**：
1. 查看监控输出，找到缺失分润的订单ID
2. 检查该订单的代理商层级关系
3. 检查该订单是否是批发商或一级代理（这些不参与分润是正常的）
4. 如果是应该分润的订单，参考[补录分润脚本](server/backfill-commissions.js)
