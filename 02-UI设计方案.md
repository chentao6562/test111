## 八、交互规范

### 8.1 加载状态

```
【页面加载】
- 首次加载：骨架屏
- 下拉刷新：顶部loading动画
- 上拉加载：底部"加载中..."

【按钮加载】
- 提交时：按钮显示loading，禁用点击
- 完成后：恢复正常状态

【空状态】
- 统一空状态插画 + 提示文案
- 可带操作按钮（如"去逛逛"）
```

### 8.2 反馈提示

```
【Toast提示】
- 成功：绿色勾 + 文字，1.5秒自动消失
- 失败：红色叉 + 文字，1.5秒自动消失
- 加载：loading + 文字

【弹窗确认】
- 标题 + 内容 + 取消/确定按钮
- 危险操作：确定按钮红色

【消息通知】
- 顶部下滑通知条
- 3秒自动消失或手动关闭
```
